# Data licenses (Okanka Mini)

Checked on 2026-10-16 via the Hugging Face dataset cards / API. Nothing below was generated by
OpenAI, Anthropic or Google models. Raw data and generated shards are **not** committed to this repo
(`data/` is git-ignored except the small template-generated `data/identity_tr.jsonl`).

## SFT (chat) data — accepted

| Dataset | Rows used | License | Provenance | Notes |
|---|---|---|---|---|
| [CohereLabs/aya_dataset](https://huggingface.co/datasets/CohereLabs/aya_dataset) (formerly CohereForAI/aya_dataset) | `language == "Turkish"`: 4,046 prompt/completion pairs | **Apache-2.0** | Human-written/annotated by Aya community contributors | Main instruction data. |
| [OpenAssistant/oasst2](https://huggingface.co/datasets/OpenAssistant/oasst2) | `lang == "tr"`, not deleted, not synthetic, review passed: 9 conversations (best-ranked path per tree) | **Apache-2.0** | Human-written (crowd-sourced) | Very few Turkish rows, included anyway. |
| Turkish Wikipedia template QA (built by `okanka/prepare_sft_data.py`) | 12,000 (default) | **CC BY-SA** (derived from Wikipedia) | Human-written article leads + fixed Turkish question templates | Teaches "X nedir / hakkında bilgi ver" answering style. |
| `data/identity_tr.jsonl` (built by `okanka/make_identity.py`) | 260 | MIT (ours) | Python templates, no LLM | Okanka Mini identity + honesty notes. |

Resulting files (default settings, seed 42): `data/sft/sft_tr_train.jsonl` 15,253 conversations, `data/sft/sft_tr_val.jsonl` 802
(5% random hold-out of Aya + OASST2 + Wikipedia QA). In SFT, the train file is repeated 2x and identity 4x.

## Rejected candidates (and why)

| Candidate | Reason |
|---|---|
| Alpaca / "Turkish-Alpaca" style sets (e.g. TFLai/Turkish-Alpaca, merve/turkish_instructions and similar) | Source data generated by OpenAI models (text-davinci-003 / GPT-3.5/4) and/or translated with GPT; OpenAI-generated content is excluded by policy. |
| atasoglu/databricks-dolly-15k-tr | Original Dolly is human-written (CC BY-SA 3.0) but this Turkish version is machine-translated with `googletrans` (Google Translate, unofficial API) -> Google-model output, excluded. |
| GPT-translated GSM8K/MMLU/ARC Turkish sets (various) | Translated with GPT models; excluded. |
| CohereLabs/aya_collection(_language_split) `turkish` (~1 GB) | Apache-2.0 at collection level, but mostly machine-translated with NLLB-3.3B (model weights CC-BY-NC) and mixes sources of varying provenance (e.g. translated SODA, which was itself generated by GPT-3.5). Not used by default; could be revisited subset-by-subset. |
| HuggingFaceTB/smol-smoltalk (nanochat's default SFT) | English; synthetic (generated with open models). Not needed for a Turkish model, left only in the `--mixture upstream` path. |
| MMLU / GSM8K / ARC / HumanEval (nanochat evals) | English benchmarks; disabled for the Turkish mixture. |

# Okanka Mini

**TR —** Okanka Mini, [Seozit.com](https://seozit.com) tarafından **tamamen sıfırdan** (rastgele ağırlıklarla başlayarak, hiçbir hazır modelin ağırlıkları kullanılmadan) eğitilmiş, deneysel ve küçük bir **Türkçe** sohbet modelidir. Kod tabanı Andrej Karpathy'nin açık kaynak [nanochat](https://github.com/karpathy/nanochat) projesinden (MIT) uyarlanmıştır.

**EN —** Okanka Mini is a small, experimental **Turkish** chat model trained **completely from scratch** (random init, no pretrained weights) by Seozit.com, using an adapted fork of Andrej Karpathy's MIT-licensed [nanochat](https://github.com/karpathy/nanochat).

## Data / Veri

- Pretraining: FineWeb-2 `tur_Latn` (ODC-By 1.0, Common Crawl ToU) + Turkish Wikipedia 20231101.tr (CC BY-SA, GFDL)
- SFT: CohereLabs/aya_dataset Turkish subset (Apache-2.0, human-annotated), OpenAssistant/oasst2 Turkish rows (Apache-2.0, human-written), template QA built from Turkish Wikipedia lead paragraphs (CC BY-SA), and template-generated identity conversations.
- No data generated by OpenAI / Anthropic / Google models was used.

See `DATA_LICENSES.md` for details.

## Limitations / Sınırlamalar

**TR:** Bu çok küçük bir modeldir (GPT-2 small/medium seviyesine yakın). Basit Türkçe cümleler kurar, ama bilgileri sıkça yanlıştır, akıl yürütme ve matematikte zayıftır, internete erişimi yoktur. Önemli kararlar için kullanmayın.

**EN:** This is a very small model (roughly GPT-2-small/medium class). It writes simple Turkish, but facts are often wrong, reasoning and math are weak, and it has no web access. Do not use it for anything important.

## Usage

```bash
git clone <okanka-mini repo>   # nanochat fork with Okanka patches
pip install torch tiktoken rustbpe filelock huggingface_hub
python - <<'EOF'
import os
from huggingface_hub import snapshot_download
d = snapshot_download("<user>/okanka-mini")
os.environ["NANOCHAT_BASE_DIR"] = d
os.environ["NANOCHAT_TOKENIZER_DIR"] = os.path.join(d, "tokenizer")
EOF
NANOCHAT_BASE_DIR=<that dir> python -m scripts.chat_cli -i sft -p "Merhaba, sen kimsin?"
```
